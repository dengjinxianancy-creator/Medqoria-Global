# Medqoria Global website

Responsive, no-build static website. Open `index.html` in a browser for a local preview.

## Before launch

The presentation provided `info@domain` as a placeholder. Update `contactEmail` in `site-config.js` to the company’s real monitored inbox before sharing this site with prospective clients. The Pages workflow uses the default GitHub URL; no custom domain is configured.

## GitHub Pages

`.github/workflows/deploy.yml` publishes the repository root on pushes to `main` and can also be run manually from Actions. In repository settings, select **Pages → Build and deployment → Source → GitHub Actions** if it is not already selected. The expected URL is `https://dengjinxianancy-creator.github.io/Medqoria-Global/`.
